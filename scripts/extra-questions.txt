B~2~A injeção de dependências permite:~Receber dependências geridas pelo contêiner~Eliminar todos os objetos Java~Dispensar interfaces HTTP~Executar toda consulta no navegador~DI entrega as dependências, reduzindo a necessidade de o objeto construí-las diretamente.
B~2~Em JpaRepository<Aluno, Long>, Long representa:~O tipo do identificador da entidade~O tempo máximo da requisição~O nome da tabela~O tamanho obrigatório de cada campo~Os parâmetros genéricos indicam entidade e tipo do ID.
B~2~Qual anotação captura o valor de id em uma rota /alunos/{id}?~@PathVariable~@Entity~@Document~@Service~PathVariable captura parte variável da URL; RequestBody lê o corpo.
B~2~Qual sequência de camadas é usual numa API com Spring?~Controller, service, repository, banco~Banco, View, dispatcher, CSS~Repository, navegador, WSDL, modelo gráfico~Controller, driver de tela, reducer, props~O controller recebe, o serviço coordena regras e o repositório acessa persistência.
B~3~No RabbitMQ, uma exchange serve principalmente para:~Rotear mensagens para filas conforme bindings~Substituir o consumidor como processador de negócio~Armazenar páginas JSP~Executar consultas JPA~Exchange roteia; filas mantêm entregas para os consumidores.
B~3~Uma exchange direct normalmente usa:~Correspondência de routing key com binding key~Sempre todas as filas, ignorando chaves~Somente a ordem alfabética dos consumidores~Chaves de partição Cassandra~Direct usa correspondência; fanout distribui a todas as filas vinculadas.
B~3~Um consumidor recebe novamente uma mensagem após falha. Que característica ajuda a evitar efeitos duplicados?~Processamento idempotente~Adicionar um novo botão~Remover todos os acknowledgments~Trocar JSON por XML sem outra mudança~Idempotência permite repetir a operação sem duplicar seu efeito pretendido.
B~3~Em JMS, Queue e Topic representam respectivamente:~Fila ponto a ponto e destino publish/subscribe~Banco relacional e banco documental~Servlet e página JSP~Request e Response HTTP~São os dois domínios clássicos de mensageria; não são tecnologias de persistência.
B~4~No SOAP, qual documento descreve o contrato do serviço?~WSDL~JSX~BSON~CQL~WSDL descreve a interface do serviço; SOAP usa mensagens XML.
B~4~Um serviço devolve exatamente os campos pedidos pelo cliente por meio de um schema e resolvers. A tecnologia é:~GraphQL~JDBC~JMS~HSTORE~GraphQL permite consultas com seleção de campos e resolução por schema.
B~4~Qual anotação é característica de JAX-RS para definir caminho de recurso?~@Path~@Entity~@Id~@WebMethod~JAX-RS está associado a REST; WebMethod aparece no contexto de SOAP/JAX-WS.
B~4~Uma resposta REST precisa ser obrigatoriamente JSON?~Não; pode utilizar outras representações, como XML~Sim; REST é o nome de um formato JSON~Sim; XML só existe em bancos~Não; REST proíbe qualquer corpo de resposta~REST é estilo arquitetural e não impõe um único formato de representação.
